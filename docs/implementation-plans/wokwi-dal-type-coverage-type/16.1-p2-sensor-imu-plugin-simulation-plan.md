## 0. v2.0.0 修订摘要与设计护城河

1. **确立三维抽象护城河**：
   - 彻底冻结统一标准 **`category: sensor` ➔ `type: imu`**，淘汰裸芯片命名（`mpu9250`）。
   - 以细分 `variant` 消化芯片拓扑：`mpu6050_i2c`（6轴/0x68）、`mpu6500_i2c`（6轴/0x70）、`mpu9250_i2c`（9轴/0x71）。
2. **升级运动学物理仿真模型（Kinematics Model）**：
   - 淘汰静态常量输出，引入重力加速度矢量 3D 姿态投影（Roll/Pitch/Yaw ➔ $A_x, A_y, A_z$），支持滤波与姿态解算算法闭环。
3. **补齐 UniSim 全生命周期与时间安全**：
   - 严密实现 `onBound`, `onPinChange`, `onReset`, `onPropertyChange`, `serializeState`, `deserializeState`, `onPowerOff`, `onDestroy`；
   - 状态通道使用 `createThrottlePublish(intervalUs = 33_000n)`（30fps 虚拟时钟节流），彻底消除事件风暴。
4. **硬件级外设行为高保真**：
   - 支持大端序（Big-Endian）16 位寄存器拼装；
   - 真实支持 `PWR_MGMT_1` 软复位与时钟源管理；
   - 支持 `INT` 中断引脚（Data Ready 与读后清零）；
   - 在 `mpu9250_i2c` 下支持 I2C Bypass 直通访问内部 AK8963 磁力计（地址 `0x0C`）。

## 1. 任务背景与架构目标

### 1.1 遵循“三维抽象设计心法”与 SSOT 规范

根据 [`00-master-execution-plan.md`](./00-master-execution-plan.md) §1.2 与 [`00.1-category-type-variant-wokwi-ssot.md`](./00.1-category-type-variant-wokwi-ssot.md) §2.4 的强制约束：

1. **`type` = 驱动护城河（严禁使用芯片型号命名）**：
   - 惯性测量单元外设统一归属于 **`category: sensor`** 下的 **`type: imu`**。
   - 严禁用 `mpu6050` 或 `mpu9250` 直接立为独立 `type`。否则破坏 DAL 设备树一致性、导致 C 侧 `app_codegen` 识别失败，破坏向后兼容。
2. **`variant` = 同族避风港（收拢芯片拓扑）**：
   - MPU 家族芯片差异在 `type: imu` 内部以细分 `variant` 枚举收拢：
     - `mpu6050_i2c`：6 轴（3 轴加速度 + 3 轴陀螺仪），I2C 接口，`WHO_AM_I` 默认 `0x68`；
     - `mpu6500_i2c`：6 轴，I2C 接口，`WHO_AM_I` 默认 `0x70`；
     - `mpu9250_i2c`：9 轴（6 轴 IMU + AK8963 3 轴磁力计），I2C 接口，`WHO_AM_I` 默认 `0x71`；
   - 对外 C API（`dal_imu_*`）和 Role 契约保持 100% 稳定一致。
3. **原生组件对齐（Native Wokwi Match）**：
   - 前端完美对齐 Wokwi 原生 WebComponent `<wokwi-mpu6050>`，实现 1:1 引脚拓扑、动态 3D 姿态/加速度可视化以及双总线物理流传输。

## 2. 硬件拓扑与引脚契约规范

### 2.1 物理引脚拓扑 (Pinout Topology)

严格遵循 SSOT §2.4 表格定义，`imu` 标准变体采用 8 引脚拓扑：

| 引脚名 | 物理语义 | pinType | simRole | required | 说明 |
|---|---|---|---|:---:|---|
| **VCC** | 供电正极 (3.3V / 5V) | `power` | `power` | `false` | 仿真电源轨检查 |
| **GND** | 信号地 (0V) | `ground` | `ground` | `false` | 仿真接地参考 |
| **SCL** | I2C 串行时钟线 | `i2c_scl` | `signal` | `true` | Class 4 硬件 I2C 时钟 |
| **SDA** | I2C 串行数据线 | `i2c_sda` | `signal` | `true` | Class 4 硬件 I2C 双向数据 |
| **AD0** | I2C 地址选择引脚 | `digital_in` | `signal` | `false` | **低电平/悬空 = 0x68；高电平 = 0x69** |
| **INT** | 中断输出引脚 | `digital_out` | `signal` | `false` | 数据就绪/运动唤醒中断脉冲 |
| **XCL** | 辅助 I2C 主机时钟 | `digital_out` | `signal` | `false` | 外挂磁力计/气压计时钟线（六轴模式赋 `-1` 哨兵） |
| **XDA** | 辅助 I2C 主机数据 | `bidirectional`| `signal` | `false` | 外挂磁力计/气压计数据线（六轴模式赋 `-1` 哨兵） |

### 2.2 动态从机地址判定规则

设备的 I2C 从机地址遵循：
- **静态属性优先**：若 `wink-app.json` 中配置了 `address`，直接采用（常用 `104` 即 `0x68`，或 `105` 即 `0x69`）；
- **动态引脚实时判定**：若未配置或处于动态引脚仿真模式，地址由 `AD0` 电平决定：
  $$\text{Address} = 0x68 \mid (\text{AD0} == \text{HIGH} ? 1 : 0)$$
  当 MCU 在运行过程中切换 AD0 GPIO 时，插件实时在总线上切换注册地址。

## 3. 仿真模型与物理学运动学模型

### 3.1 重力矢量投影与物理学模型 (Kinematics)

为支持姿态滤波算法闭环，模型维护空间姿态角（欧拉角：Roll $\phi$, Pitch $\theta$, Yaw $\psi$）：

1. **重力加速度投影**（1g 静态重力，±2g 量程下灵敏度为 $16384 \text{ LSB/g}$）：
   $$A_x = -16384 \cdot \sin(\theta)$$
   $$A_y = 16384 \cdot \sin(\phi) \cos(\theta)$$
   $$A_z = 16384 \cdot \cos(\phi) \cos(\theta)$$
   *默认水平静止态（$\phi=0, \theta=0$）*：$A_x = 0, A_y = 0, A_z = +16384$。
2. **陀螺仪角速度**（±250 dps 量程下灵敏度为 $131 \text{ LSB/(°/s)}$）：
   静止状态输出零漂与高斯白噪声微扰（可选），动态旋转输出角速度矢量 $\omega_x, \omega_y, \omega_z$。
3. **片上温度模型**：
   $$T_{\text{degC}} = \frac{\text{TEMP\_OUT} - \text{offset}}{333.87} + 21.0$$
   默认输出室温 $25.0^\circ\text{C}$（$\text{TEMP\_OUT} \approx 1334$）。

### 3.2 寄存器空间映射与大端序拼装 (Big-Endian)

插件内部维护 128 字节标准寄存器空间。16 位传感器数值必须以**大端序（高字节在前，低字节在后）**拼装：

```ts
function pack16(regHigh: number, val: number): void {
  const u16 = val < 0 ? (val + 0x10000) & 0xffff : val & 0xffff;
  registers[regHigh]     = (u16 >> 8) & 0xff; // High byte
  registers[regHigh + 1] = u16 & 0xff;        // Low byte
}
```

**关键寄存器分布**：
```
[0x19]: SMPLRT_DIV      (采样分频)
[0x1A]: CONFIG          (DLPF 配置)
[0x1B]: GYRO_CONFIG     (量程: ±250, ±500, ±1000, ±2000 °/s)
[0x1C]: ACCEL_CONFIG    (量程: ±2g, ±4g, ±8g, ±16g)
[0x37]: INT_PIN_CFG     (中断引脚极性、BYPASS_EN 旁路使能)
[0x38]: INT_ENABLE      (中断使能: DATA_RDY_EN = bit 0)
[0x3A]: INT_STATUS      (中断状态: 读取后自动清零)
[0x3B..0x40]: ACCEL_X/Y/Z (高低字节)
[0x41..0x42]: TEMP_OUT    (高低字节)
[0x43..0x48]: GYRO_X/Y/Z  (高低字节)
[0x6B]: PWR_MGMT_1      (电源管理: 0x80 复位, 0x40 休眠, CLKSEL)
[0x6C]: PWR_MGMT_2      (待机控制)
[0x75]: WHO_AM_I        (MPU6050=0x68, MPU6500=0x70, MPU9250=0x71)
```

### 3.3 中断线（INT）与时序行为

1. 当更新完成一组传感器数据且 `INT_ENABLE & 0x01`（Data Ready）置位时：
   - 将 `INT_STATUS` bit 0 置 1；
   - 根据 `INT_PIN_CFG` 的 `ACTL` 极性，将 `INT` 引脚拉至有效电平；
2. 当主机通过 I2C 读取 `INT_STATUS (0x3A)` 后：
   - 自动清除 `INT_STATUS` 为 0；
   - 自动恢复 `INT` 引脚为非有效电平（Read-to-Clear 真实硬件行为）。

### 3.4 磁力计旁路模式（AK8963 Bypass）

在 `mpu9250_i2c` 变体下，MPU9250 芯片合封了 AK8963 3 轴磁力计：
- 当向 `INT_PIN_CFG (0x37)` 写入数据使 `BYPASS_EN`（bit 1）置位时：
  - 插件自动在当前 I2C 总线上激活地址为 `0x0C` 的虚拟 AK8963 响应；
  - 支持 `WHO_AM_I_AK8963 (0x00)` 返回 `0x48`；
  - 支持读取磁场分量 $H_x, H_y, H_z$ 数据。

## 4. 插件契约与生命周期规范

### 4.1 基类与清单导出

- 继承 `BaseSimulationPlugin<ImuState, ImuProps>` 并实现 `I2CDevice` 接口；
- `timingModel: 'event-driven'`；
- 默认导出契约（FS 发现器强制校验）：`export default { manifest, manifestFactory, PluginClass }`。

### 4.2 完整生命周期钩子职责表

| 生命周期钩子 | 执行时机与职责定义 |
|---|---|
| `onBound(ctx, pinMapping, props)` | 建立引脚映射反查；解析 `variant` 与地址属性；分配 128 字节预置内存；注册 I2C 总线从机；发布初始状态。 |
| `onPinChange(pin, level, atUs)` | 监听 `AD0` 电平变化：若电平改变且未锁定静态地址，动态更新 I2C 监听地址。四值逻辑 HI_Z 按悬空（接地 0x68）处理。 |
| `onReset()` | 硬件复位：寄存器重载出厂值（`PWR_MGMT_1` 恢复 `0x01`，`WHO_AM_I` 恢复），重力矢量重置为水平静态，清空 INT 引脚。 |
| `onPropertyChange(key, old, neu)` | 监听测试台或 UI 注入的姿态参数（`roll`, `pitch`, `yaw`, `temperature`），触发重力加速度与传感器数据重算。 |
| `serializeState()` | 序列化当前寄存器数组、姿态角、游标、INT 电平与 I2C 统计计数，用于快照回放与时间旅行断言。 |
| `deserializeState(state)` | 恢复寄存器与状态，避免恢复瞬间物理量跳变。 |
| `onPowerOff() / onPowerOn()` | 掉电时停止总线响应与中断输出；上电时重新使能 I2C 从机。 |
| `onDestroy()` | 显式解绑 I2C 总线监听；注销虚拟定时器；避免内存泄漏。 |

### 4.3 状态通道设计 (StateChannels)

通过虚拟时钟节流发布（`intervalUs: 33_000n`，30fps）：

| 通道名 | 类型 | 默认值 | 物理量纲 (ADR-0056) | 语义说明 |
|---|---|---|---|---|
| `whoAmI` | `number` | `0x68` / `0x71` | — | 当前器件识别码 |
| `pwrMgmt1` | `number` | `0x01` | — | 电源与时钟源状态 |
| `accelX` | `number` | `0` | `accel_lsb` | X 轴加速度 (LSB) |
| `accelY` | `number` | `0` | `accel_lsb` | Y 轴加速度 (LSB) |
| `accelZ` | `number` | `16384` | `accel_lsb` | Z 轴加速度 (1g 静态重力) |
| `gyroX` | `number` | `0` | `gyro_lsb` | X 轴角速度 (LSB) |
| `gyroY` | `number` | `0` | `gyro_lsb` | Y 轴角速度 (LSB) |
| `gyroZ` | `number` | `0` | `gyro_lsb` | Z 轴角速度 (LSB) |
| `tempDegc` | `number` | `25.0` | `temp_degc` | 片上温度（摄氏度） |
| `writeCount` | `number` | `0` | — | I2C 写事务计数 |
| `readCount` | `number` | `0` | — | I2C 读事务计数 |

## 5. 三仓闭环验证与质量卡点 (Quality Gates)

落地本外设插件时必须执行以下 5 项测试验收：

1. **插件单体构建与 Manifest 校验**：
   - `vite.config.sim.ts` 独立构建 `dist/simulation.js`；
   - 运行 `bun scripts/emit-sim-manifests.mjs` 正确生成 `dist/manifest.json`，无 TS 编译警告与类型漂移。
2. **DeviceTree 生成验证**：
   - 在 `wink-app.json` 中配置：
     ```json
     "devices": {
       "imu": {
         "type": "imu",
         "variant": "mpu9250_i2c",
         "address": 104,
         "sda_pin": 21,
         "scl_pin": 22
       }
     }
     ```
   - 验证 `winkcli build sim` 生成的 `unisim-assets/device-tree.json` 正确导出 `imu` 节点并绑定对应引脚。
3. **ESP-IDF 原厂 `i2c_basic` 验收**：
   - 运行 `run_esp32_headless_evidence.ps1 -App i2c_basic -Reporter json`；
   - 验证原厂 `i2c_basic_example_main.c` 成功读取 `WHO_AM_I = 71` 并通过 `ASSERT_BUS_PAYLOAD`。
4. **Canary 变异击杀（Fail-Loud 验证）**：
   - 注入 matcher 篡改变异，验证断言引擎即刻 Fail-Loud 拒绝并捕获差分。
5. **门检全覆盖**：
   - `python wink-micro-app/vendor/esp_idfv61/.governance/gates/run_gates.py` 退出码 0，无任何 Gate 1~4 违规。
