## 1. 任务背景与核心目标

### 1.1 为什么将 51 裸机联调作为独立的 Part 2？

在数码管三部曲体系中，Part 1 完成了**物理引脚电平驱动的仿真插件与亮度积分模型**，Part 3 将完成**跨平台标准 DAL 驱动（支持 ESP32/Wasm 等 32 位现代平台）**。将纯 8051 裸机验证独立设为 Part 2 具备无可替代的战略价值：

1. **真实硬件解耦验证（Pin-Level Decoupling Proof）**：
   在真正的高保真仿真系统中，前端外设插件对上层固件形态完全无感知。无论驱动引脚的是 Linux 驱动、ESP-IDF 代码还是最原始的 8051 汇编/裸机 C，外设插件应当忠实且毫无区别地响应引脚电平跳变。
2. **教学领域最高频的外设载体**：
   高校单片机教学中，90% 以上的动态扫描实验基于 AT89C51/C52 配合 8 位数码管展开。8 位动态扫描是理解「视觉暂留、定时器中断、IO 口准双向驱动、总线冲突、消隐时序」的核心教学节点。
3. **为 Part 3 标准 DAL 驱动提供基准对照组（Golden Reference）**：
   通过 Part 2 沉淀出一套标准的裸机时序性能基线（刷新率 $\approx 1\,\text{kHz}$，位选占空比 $\approx 12.5\%$，微秒级消隐），Part 3 开发高层 DAL 跨平台驱动时便可直接以此基线为参照，确保现代驱动在保真度上不发生倒退。

### 1.2 闭环目标

- **固件层**：编写完全符合 Keil C51 标准语法的纯裸机源码（`REGX52.H`，无侵入），支持 Timer0 中断动态扫描与主循环轮询双模式。
- **消隐对比（Anti-Ghosting Verification）**：固件提供消隐与未消隐宏开关，真实复现教学现场中“未消隐产生鬼影”与“严密消隐清爽显示”的对照。
- **端到端闭环**：通过 `wink-micro-os` 的 `frameworks/mcs51` 拦截层将 8051 固件在 Host/UniSim 环境中运行，P0/P2 的引脚输出实时喂给 Part 1 交付的 `SegDisplayPlugin`，断言解码文本稳定输出目标字符（如 `'12345678'`）、稳态亮度 $\ge 200$、刷新率 $\approx 1000\,\text{Hz}$。

## 2. 硬件拓扑与引脚连接契约规范

### 2.1 AT89C52 标准板级接线

采用国产高校 51 开发板（如普中、天祥）最标准的数码管接口方案：

| 51 端口位 | MCU 线性引脚号 (`global_pin`) | 外设插件引脚 | 角色语义 | 典型物理连接 |
|---|:---:|---|---|---|
| **P0.0** | 0 | `A` | 顶部横段 (a) | 段选总线 |
| **P0.1** | 1 | `B` | 右上竖段 (b) | 段选总线 |
| **P0.2** | 2 | `C` | 右下竖段 (c) | 段选总线 |
| **P0.3** | 3 | `D` | 底部横段 (d) | 段选总线 |
| **P0.4** | 4 | `E` | 左下竖段 (e) | 段选总线 |
| **P0.5** | 5 | `F` | 左上竖段 (f) | 段选总线 |
| **P0.6** | 6 | `G` | 中间横段 (g) | 段选总线 |
| **P0.7** | 7 | `DP` | 小数点 (dp) | 段选总线 |
| **P2.0** | 16 | `DIG1` | 第 1 位（最左高位）公共端 | 位选线 0 |
| **P2.1** | 17 | `DIG2` | 第 2 位公共端 | 位选线 1 |
| **P2.2** | 18 | `DIG3` | 第 3 位公共端 | 位选线 2 |
| **P2.3** | 19 | `DIG4` | 第 4 位公共端 | 位选线 3 |
| **P2.4** | 20 | `DIG5` | 第 5 位公共端 | 位选线 4 |
| **P2.5** | 21 | `DIG6` | 第 6 位公共端 | 位选线 5 |
| **P2.6** | 22 | `DIG7` | 第 7 位公共端 | 位选线 6 |
| **P2.7** | 23 | `DIG8` | 第 8 位（最右低位）公共端 | 位选线 7 |

> **注**：8051 端口线性映射公式为 `(port_num << 3) | bit_num`：
> - P0 (Port 0): 0 ~ 7
> - P2 (Port 2): 16 ~ 23

### 2.2 极性矩阵契约

教学板典型组合：
- **数码管制造极性**：共阴极（Common Cathode）。段选线送高电平（1）点亮对应段。
- **位驱电路**：
  - 方案 A（教学板默认直驱/反相译码器 74HC138）：低电平有效选通（`DIGn = 0` 导通）。
  - 方案 B（经 NPN 三极管高侧驱动）：高电平有效选通（`DIGn = 1` 导通）。
- **Part 2 验证基线**：以教学最普及的 **共阴极直驱模式（段选高有效 `segActiveLevel='high'`，位选低有效 `digitActiveLevel='low'`）** 为主验证基线，同时用宏支持高有效位驱校验。

## 3. 8051 裸机固件工程设计

### 3.1 固件文件架构

在 `wink-micro-os/test/mcs51/samples/` 下新建：
`seg_display_scan.c` —— 完全保持原汁原味的 Keil C51 风格代码。

### 3.2 固件设计核心要素

```c
#include <REGX52.H>
#include <intrins.h>

/* 共阴极数码管 0-9 段码表 (A=bit0 .. DP=bit7) */
unsigned char code SEG_TABLE[] = {
    0x3F, /* 0 */
    0x06, /* 1 */
    0x5B, /* 2 */
    0x4F, /* 3 */
    0x66, /* 4 */
    0x6D, /* 5 */
    0x7D, /* 6 */
    0x07, /* 7 */
    0x7F, /* 8 */
    0x6F  /* 9 */
};

/* 待显示数据缓冲区（8位） */
unsigned char display_buf[8] = {1, 2, 3, 4, 5, 6, 7, 8};
```

### 3.3 两种扫描架构

1. **定时器扫描模式（Timer0 ISR 1ms 典型）**：
   - 12MHz 晶振下，1ms 定时器初值：`TH0 = 0xFC; TL0 = 0x18;`
   - ISR 中维护 `current_digit`（0~7）：
     ```c
     void Timer0_ISR(void) interrupt 1 {
         TH0 = 0xFC;
         TL0 = 0x18;

         /* 消隐核心步骤：
          * 1. 关断当前位选（防止段码跳变映射到旧位上）
          * 2. 送出下一位段选码
          * 3. 开启下一位位选
          */
     #if ENABLE_BLANKING
         P2 = 0xFF; /* 关位选（消隐） */
     #endif
         P0 = SEG_TABLE[display_buf[current_digit]];
         P2 = ~(1 << current_digit); /* 开位选 */

         current_digit = (current_digit + 1) & 0x07;
     }
     ```
2. **主循环轮询模式（Super-loop with Cooperative Yield）**：
   - 为兼容 Host 非中断协程环境，支持在 `main()` 超循环中通过微步延时 `_nop_()` 推进切位。

### 3.4 消隐与鬼影注入控制

固件通过编译宏 `#define ENABLE_BLANKING 1` 与 `0` 切换：
- `ENABLE_BLANKING = 1`：严格先关位选再送段码，稳态鬼影段亮度为 0。
- `ENABLE_BLANKING = 0`：送段码与关位选时序颠倒，产生 50µs 级的总线混叠，向邻位泄露段码电平，仿真插件的占空比积分器将忠实还原出亮度在 $5 \sim 30$ 之间的微弱暗影。

   - 编译 51 C 固件为 Host 可执行目标；
   - 拦截 P0 / P2 输出，记录波形与时序特征（选通脉宽、消隐死区时间、扫描周期）；

## 6. 验收标准与质量卡点 (Quality Gates)

1. **代码规范门禁**：
   - 8051 固件保持纯正 Keil C51 风格，经 CMake 清洗 pass 零警告编译为 C++17 沙箱代码；
   - C 测试驱动遵循 `wink_runtime` 协程规范，无内存泄漏、无死锁。
2. **闭环功能门禁**：
   - 8051 裸机固件驱动下，`SegDisplayPlugin` 输出 `text` 精确等于预设缓冲区内容（如 `'12345678'`）；
   - 8 位的段掩码 `segMask` 100% 正确。
3. **时序与保真度门禁**：
   - 测得刷新频率在 $800 \sim 1200\,\text{Hz}$ 之间；
   - 消隐生效时画面无鬼影，消隐缺失时鬼影亮度在物理预估区间（$5 \sim 30$），不误触发逻辑置位。
4. **交付就绪**：
   - 为 Part 3（跨平台 DAL 驱动）提供完全对齐的硬件接线契约与参考时序模型。
