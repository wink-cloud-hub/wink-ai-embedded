## 3. 原型注册和可执行准入

### 3.1 冻结注册表，消除字段漂移

每个原型注册项必须包含：稳定 ID/版本/Tier、存在于能力目录的能力 ID、适用的 backend/SoC/profile/配置分支、业务 Claims、具体观察与单位、原始正常场景、L1/L2 recipe、错误域、时限来源、恢复策略、代表配置和必要运行时能力。

现有 `archetype_adc_sampling.yaml` 引用 `cap.analog.adc_continuous`，目录中的实际 ID 是 `cap.analog.adc_dma`；先对账语义和消费者，不只替换字符串。单次 ADC 配置不能不加区分地继承连续采样的背压 Claims。

当前 pipeline 消费 `app_entry.proofplan`，Resolver 使用 `inherits`。新 `archetype_ref` 或配置级引用如需引入，必须先冻结 Schema、迁移和全部消费者，证明真实命令参数/配置选择生效；单独写入引用字段不能算完成。多配置绑定依实际设计实施，严禁默认选第一个 execution。

Claim 与算子 ID 唯一、引用完整，继承不能删掉必需义务；差量覆盖须核验类型、适用性、单位和极性。Resolver 仅证明结构的部分性质；逐族遍历与 runtime/gate conformance 验证所有注册项，不能仅测试 archetype_start。

### 3.2 每族需要真实准入证明

| 准入面 | 必需证据 |
|---|---|
| 能力与解析 | CLI/Step/Target/Matcher/Probe ABI/错误符号真实可用；静态门禁识别同一场景，unsupported 明确报缺口 |
| 正确基线 | 代表配置在冻结输入下完成原业务出口断言，不只初始化、电源或网络就绪 |
| 固件依赖与实现变异 | fixture 和预期不变；停用核心行为及有效非等价变异使指定正常断言失败；编译/宿主失败不计击杀 |
| 故障与恢复 | 适用外部故障确实生效，错误处理或声明的受控终止符合契约；撤销后新基线恢复 |
| 错误适用性 | 错 SoC/配置分支/能力、无效观察、空 Claim/recipe/负例拒绝；正确配置仍可通过 |
| 版本与覆盖 | 原型、依赖、runner 和规则指纹绑定；保留实际覆盖与未覆盖配置，父原型通过不自动认证所有子应用 |

例如 I2C NACK、认证失败、HTTP 503 或 Broker 断连通常属于故障处理实验；要证明实现缺陷敏感性，应另有破坏请求生成、收包处理、状态迁移等业务的有效变异。不能把环境变坏后正常场景失败统称 implementation_mutation。

先让每族一项代表配置通过上述准入，再验证不同芯片/profile/分支的差异。公共配方复用，业务特定期望与编译配置留在对应配置合同中，不使用全局过宽 Matcher。

## 4. 历史 46 配置的复验次序

按 T0.1 冻结的历史成员和能力依赖分组，先 1 项、再 3 项、再最多 10 项的小批，满足前置条件后逐步扩大。分组必须有完整 app_id/config_id 清单；v1.0 的 12/15/12 只是未核验估算，不用于集合验收。

1. 核对原厂摘要、实际文件映射和 SDK 版本；源文件不直接修改。Wink Manifest、门面和场景的改动独立记录，变异只发生在沙箱副本。
2. 对每个 execution 核对真实 backend/芯片/profile/sdkconfig 与条件能力依赖；例如 deep_sleep、AP/STA、GPIO/WS2812 分支分别核验。
3. 按声明业务分别审查正常、故障和恢复集合。DAC 禁止输入回读；GPTimer 检查设备计数/告警；MQTT 检查真实断连和受控重连；LEDC 按声明的渐变/阶跃子集核验。
4. ProofPlan 与完整场景在运行前冻结，由 QG-1 真实入口执行。单测、旧 twin 包或合成 Pilot 只能作为辅助材料，不能补齐缺失的新证据。
5. 每项输出资格、缺口及实际执行范围。needs_driver_fix/needs_proofplan_update 是诊断，不新增 delivery_state；应区分驱动、场景、工具、身份、需求审计、能力和环境原因。
6. 候选包只在新 run 目录留存。只有阶段四执行有效审计、适用回归与晋升，才能改正式交付态并派生看板；本阶段不直接把裁决写成 verified。

保留原 [历史裁决报告](../../../reviews/esp32/2026-10-09-esp-idf-legacy-46-triage-report.md)。本轮新复验报告使用新的时间/批次标识，列出原记录、当前原始证据、纠偏原因和未执行内容，不能覆盖历史 reviews。
